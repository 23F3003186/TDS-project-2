Autonomous Execution Flow

            

          


          

            

              
1

              

                
Receive Task & Verify Auth

                
Validates secret token and triggers run_agent asynchronously in background.

              

            


            

              
2

              

                
Render DOM & Extract Context

                
Playwright executes dynamic JavaScript to extract forms, endpoints, and instructions.

              

            


            

              
3

              

                
Cyclic Multi-Tool Reasoning

                
Executes code in Pandas/Scikit-Learn, transcribes audio, analyzes images, or charts figures.

              

            


            

              
4

              

                
Submit & Chain Next Question

                
Posts answer to target endpoint; follows new URL recursively until finished (or "END").

Environment Variables

        
Configure these variables in your .env file or Hugging Face Space settings.

      


      

        

          

            
              

                Variable
                Required
                Description
              

            
            
              

                GOOGLE_API_KEY
                Yes
                Primary Google Gemini API key used for agent reasoning.
              

              

                GOOGLE_API_KEY_2..4
                Optional
                Additional Gemini keys for rotation to avoid rate limits.
              

              

                OPENAI_API_KEY
                Yes
                Fallback API key used if Gemini keys hit quota exhaustion.
              

              

                TDS_SECRET
                Yes
                Secret token for authenticating incoming API requests.
              

              

                TDS_EMAIL
                Optional
                Email address sent alongside answer submissions.
              

              

                GITHUB_TOKEN
                Optional
                GitHub Personal Access Token for remote Gist logging.
